# Enterprise AI GTM Skill — Getting Started Guide

## What You Now Have

A **production-ready Claude skill** that:
- Appears in your Claude Code skills menu as `/enterprise-gtm`
- Works for ANY enterprise product (SaaS, DevTools, AI Services, Government)
- Automatically selects the right positioning framework
- Generates complete GTM systems in 6 weeks
- Creates 23 strategic artifacts (positioning, content, lead gen, sales)

## How to Access the Skill

### In Claude Code CLI
```bash
/enterprise-gtm
```

### In Claude Code Desktop / Web App
1. Open Claude Code
2. Click "Skills" menu (or use `/` and search)
3. Find "Enterprise AI GTM Skill"
4. Click to open or search for `/enterprise-gtm`

## Common Questions

### Q: How do I use this skill if I'm in a hurry?
**A**: Run quick framework selection (5 min). Framework tells you what to do. Then execute content + lead gen (2-3 weeks vs. 6 weeks for full positioning).

### Q: Can I use this for multiple products?
**A**: Yes. Run skill for Ask-AI, then for Risk Scoring, then for eCourt. Same skill, different outputs.

### Q: What if I don't have a proven product yet?
**A**: Use Pre-launch framework (Lean Canvas + problem validation). Focus on waitlist + founder credibility.

### Q: How long does this really take?
**A**: Framework selection = 5 min. Full positioning = 6 weeks (guided). Content + lead gen = 2-3 weeks once positioning done.

### Q: Can I apply this to B2B SaaS instead of Enterprise AI?
**A**: Yes. Framework selection will recommend Geoffrey Moore (growth) instead. Same process, different framework.

### Q: What if I already have messaging?
**A**: Use "Content Strategy" workflow. Skip positioning, jump to content calendar + lead gen.
