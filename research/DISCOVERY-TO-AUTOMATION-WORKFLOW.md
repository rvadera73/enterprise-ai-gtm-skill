## Phase 1: Brand Discovery (What We Just Created)

**Duration**: 2-4 weeks  
**Effort**: 1 workshop (3-4 hours) + 10 customer interviews + research  
**Output**: Discovery Brief document with:
- Positioning statement
- Customer segments & value propositions
- Competitive differentiation
- Brand voice guidelines
- Messaging hierarchy
- Audience-specific messaging

**Key Deliverable**:
```
DISCOVERY BRIEF: [Company Name]

1. POSITIONING STATEMENT
"We are the only [category] that [differentiation] for [audience] because [credibility]"

Example (Linear):
"We are the only issue tracker that prioritizes developer experience and speed 
for 10-200 person engineering teams because our team built fastest product tools 
at major tech companies"

2. PRIMARY AUDIENCE & VALUE PROP
Segment: Engineering managers at 10-200 person SaaS companies
Pain point: Team wasting 5+ hours/week on issue management
Outcome: Reduce time spent on issue management by 70%
Differentiation: 3x faster than Jira, built by engineers, $80/month vs. $500/month

3. MESSAGING HIERARCHY
Core: "The fastest issue tracker, so you can focus on shipping"
For Eng Managers: "Give your team back 5+ hours/week"
For CTOs: "Standardize on a tool your team loves"
For Individual Engineers: "Stop context-switching; stay in flow"

4. BRAND VOICE
Tone: Formal 8/10, Technical 9/10, Concise 9/10
Example: "We move fast. Our tool should too."
Anti-pattern: "Synergize your workflow with cutting-edge AI-powered insights"

5. PROOF POINTS
- 3x faster than Jira (benchmark data)
- Powers 5,000+ teams shipping products
- Founded by engineers from Stripe, Google, Facebook
- $800K ARR in first 12 months
```

## Phase 2: Marketing Automation (The Execution Arm)

**Duration**: 25 minutes per campaign (ongoing)  
**Effort**: Zero manual team effort (fully automated)  
**Output**: 30+ professional marketing assets per campaign

### How Automation Uses Discovery

The marketing factory reads the **Discovery Brief** and generates all content **aligned with positioning**:

```
INPUT TO AUTOMATION ENGINE:

Topic: "Linear Reduces Triage Time for Growing Engineering Teams"

Brand Config (from Discovery Brief):
- Positioning: "Only issue tracker that prioritizes developer experience"
- Segment: "Engineering managers at 10-200 person startups"
- Key message: "Save 5+ hours/week on issue management"
- Tone: Formal, technical, concise
- Voice example: "We move fast. Our tool should too."
- Proof points: 3x faster, 5,000+ teams, $800K ARR

PROCESSING:

→ Positioning Alignment Filter
  (Don't generate generic SaaS content; use this specific positioning)

→ Audience-Specific Messaging Router
  (Engineering Manager version: emphasize team productivity
   CTO version: emphasize standardization
   Individual Engineer version: emphasize flow state)

→ Brand Voice Enforcer
  (Remove marketing clichés, technical language, concise sentences)

→ Proof Point Injector
  (Include "3x faster than Jira" not "fast issue tracker")

→ Competitive Differentiation Mapper
  (Explicitly position vs. Jira, GitHub Issues, Asana)

OUTPUT: 30+ Assets (all positioning-aligned)
```

## The Integration: What Makes This Work

### Input to Output Example

```
DISCOVERY BRIEF INPUT:
├─ Positioning: "Only issue tracker that prioritizes speed + developer experience"
├─ Segment: "Engineering managers at 10-200 person startups"
├─ Key message: "Save 5+ hours/week on issue management"
├─ Tone: Formal, technical, concise
├─ Proof points: "3x faster", "5,000+ teams", "$80/month"
└─ Competitive gap: Jira bloated, GitHub Issues limited

TOPIC INPUT:
"Linear Saves Engineering Managers 5+ Hours Per Week"

MARKETING FACTORY PROCESSING:
├─ Filter for positioning alignment
│  (Avoid: "powerful collaboration tool for teams")
│  (Use: "fastest issue tracker for engineers")
│
├─ Route by audience
│  (Eng Manager: emphasize hours saved + team productivity)
│  (CTO: emphasize standardization + cost)
│  (Engineer: emphasize speed + UX)
│
├─ Apply brand voice
│  (Technical language, concise sentences, professional tone)
│  (Avoid marketing clichés: "unleash", "empower", "transform")
│
├─ Inject proof points
│  (Always reference "3x faster", "5,000+ teams", "$80/month")
│  (Never claim "best" or "only" without data)
│
└─ Map competitive differentiation
   (vs. Jira: "We're fast, they're bloated")
   (vs. GitHub: "We're feature-complete, they're limited")
   (vs. Asana: "We're developer-focused, they're generalist")

OUTPUT: 31 Assets
├─ 5 written pieces (post, thread, email, blog, case study)
├─ 6 visual assets (images for each platform)
├─ 4 videos (30sec, 60sec, explainer, demo)
├─ 2 audio assets (voiceover, podcast outline)
├─ 3 interactive tools (calculator, comparison, checklist)
├─ 4 social variants (Instagram, TikTok, LinkedIn, Reddit)
├─ 3 engagement assets (FAQ, worksheet, polls)
├─ 2 developer assets (code sample, API docs)
└─ 2 measurement assets (email sequences, landing page)

All 31 assets:
- Use the same positioning statement
- Target the same audience segments
- Apply the same brand voice
- Include the same proof points
- Reference the same competitive differentiation
```
