# Generic Positioning Process

**The 6-Week Workshop That Works for Any Product**

This process is the same whether you're positioning Ask-AI, Risk Scoring, eCourt, or any future product. The framework changes (based on product type × stage), but the process is identical.

---

## Overview

```
Week 1-2: Discovery (9 exercises)
├─ Future State Headlines
├─ Problem Definition  
├─ Customer Persona
├─ Competitive Analysis
├─ Differentiation Statement
├─ Value Proposition Mapping
├─ Messaging Hierarchy
├─ Brand Archetype
└─ Brand Promise

Week 2-3: Framework Application (tailored by type)
├─ Apply selected framework (Dunford, Moore, JTBD, etc.)
├─ Build framework-specific artifacts
└─ Create positioning statement

Week 3-4: Validation
├─ Customer interviews (5-10)
├─ Competitive analysis deepening
├─ Messaging testing
└─ Iteration based on feedback

Week 4-5: Segmentation & Messaging
├─ Segment mapping (who buys)
├─ Buyer-specific value props
├─ Proof point prioritization
└─ Messaging hierarchy per segment

Week 5-6: Operationalization
├─ Brand guidelines document
├─ Sales playbook
├─ Content calendar
└─ Launch planning
```

---

## Week 1-2: Discovery Workshop (9 Exercises)

### Exercise 1: Future State Headlines

**What**: Write 5 headlines describing your product 18 months from now (if successful)

**For Ask-AI**:
```
"Ask-AI Reduces Knowledge Search from Hours to Seconds Across Enterprise Systems"
"92% Accuracy in Conversational Enterprise Knowledge Access"
"Ask-AI Eliminates Help Desk Bottlenecks at Fortune 500 Companies"
"Cross-System Knowledge Search Standard in Enterprise IT"
"Knowledge Workers Find Answers Independently in 30 Seconds"
```

**For Risk Scoring**:
```
"AI-Powered Fraud Detection Reduces False Positives by 70%"
"Risk Scoring Model Deployed in 30 Days, Not Months"
"Institutions Prevent Fraud Before It Happens"
"ML Model Management Becomes as Easy as SaaS"
```

**Why**: Define success from customer perspective, not feature perspective

---

### Exercise 2: Problem Definition (Deep Dive)

**What**: Define the exact problem your product solves

**Structure**:
```
Current State (What customers do today):
- [Specific process or pain]
- [Time cost]
- [Money cost]
- [Risk/compliance cost]

Why Current Solutions Fail:
- [Why consulting is too slow]
- [Why point solutions fragment]
- [Why DIY is too risky]

Customer's Biggest Frustration:
- [Articulate the emotional pain]
```

**For Ask-AI Example**:
```
Current State:
- Knowledge workers search 5+ systems for answers
- 2-4 hours/day wasted searching
- $625K/year cost per 5,000 person company
- Compliance risk (no audit trail on knowledge access)

Why Current Solutions Fail:
- Google Enterprise Search: Too generic, not conversational
- Slack Search: Limited to Slack
- SharePoint Search: Clunky, not cross-system
- Build yourself: 6+ month timeline

Customer's Biggest Frustration:
- "I know the answer exists somewhere. I just can't find it."
```

---

### Exercise 3: Customer Persona (Detailed)

**What**: Create 3 buyer personas (different roles involved in decision)

**Structure per persona**:
```
Name: [Realistic name + role]
Company: [Size, industry]
Responsibilities: [What they own]
Goals: [What success looks like for them]
Pain Points: [Specific to their role]
Objections: [What they worry about]
Proof That Matters: [What convinces them]
```

**For Ask-AI Example**:

**Persona 1: Knowledge Operations Leader (Primary Buyer)**
```
Name: Jennifer, VP of Knowledge & Operations
Company: Fortune 500, 10,000 employees
Responsibilities: Help desk, knowledge management, employee productivity
Goals: Reduce help desk cost by 30%, free up team for higher-value work
Pain Points: 
  - Help desk overwhelmed with "where do I find X" questions
  - Knowledge fragmented across 5+ systems
  - No visibility into what employees are searching for
Objections:
  - "Will it work with our legacy systems?"
  - "How long to implement?"
  - "What about security?"
Proof That Matters:
  - Implementation timeline (she needs 4-6 weeks)
  - Integration approach (can't replace existing systems)
  - ROI metrics ($150K help desk savings)
```

**Persona 2: CTO (Technical Approver)**
```
Name: Marcus, CTO
Company: Fortune 500, 10,000 employees
Responsibilities: Technology strategy, system integration, security
Goals: Modernize with AI, reduce technical debt, maintain security
Pain Points:
  - Point solutions create integration nightmares
  - AI projects often fail in production
  - Security and governance concerns
Objections:
  - "Will this create data silos?"
  - "How do you handle compliance?"
  - "Vendor lock-in?"
Proof That Matters:
  - Architecture diagram (shows integration approach)
  - Compliance certifications
  - Customer technical case studies
```

### Exercise 4: Competitive Analysis

**What**: Map what competitors (alternatives) customers consider

**Structure**:
```
Direct Competitors: [Products like yours]
Indirect Competitors: [Different solutions to same problem]
Do-Nothing: [Cost of staying with status quo]

For each:
- How do they position?
- What are they good at?
- What are they missing?
- Why would someone choose you instead?
```

**For Ask-AI Example**:
```
Direct Competitors: 
- None (conversational cross-system knowledge doesn't exist)

Indirect Competitors:
- Google Enterprise Search (generic, not conversational)
- Slack Search (limited to Slack)
- SharePoint native search (clunky)
- Building custom chatbot (6+ month timeline)
- Doing nothing (accepting inefficiency)

Why Ask-AI Wins:
- vs. Google: Conversational + cross-system
- vs. Slack: Works beyond Slack
- vs. SharePoint: Modern UX, easy setup
- vs. Custom: 28 days vs. 6+ months
- vs. Doing nothing: $625K/year savings
```

### Exercise 5: Differentiation Statement

**What**: One sentence that explains why you're different (and why it matters)

**Formula**: "Unlike [competitor], [your product] [unique capability] which enables [customer benefit]"

**For Ask-AI**:
```
"Unlike fragmented search tools, Ask-AI provides a single conversational interface 
across all enterprise systems, enabling knowledge workers to find answers in 
30 seconds instead of 2-4 hours."
```

**For Risk Scoring**:
```
"Unlike point-solution risk models, our platform enables centralized risk scoring 
across multiple data sources, allowing institutions to deploy new models in 30 days 
instead of 6 months."
```

## Week 2-3: Framework Application

This is where the framework you selected (from the matrix) comes in.

### If Using Geoffrey Moore Template (Enterprise AI Service, Growth)

**Apply Moore's formula**:
```
FOR [Target Customer]
WHO [Has this problem]
[Your Product] IS [Product Category]
THAT [Key Benefit]
UNLIKE [Competitor/Alternative]
OUR [Key Differentiator]
PROVES [Proof Point]
WHICH DELIVERS [Business Outcome]
```

**For Ask-AI**:
```
FOR Enterprise HR/Operations Leaders
WHO are managing knowledge workers drowning in search across 5+ systems
ASK-AI IS a conversational knowledge platform
THAT answers questions in 30 seconds
UNLIKE Google Enterprise Search or Slack Search
OUR unique strength is cross-system search + conversational interface
PROVES 92% accuracy, 28-day deployment, 300+ users
WHICH DELIVERS $150K+ annual help desk savings per company
```

### If Using April Dunford Canvas (DevTools, Growth)

**Build Dunford's 10-step framework**:
```
1. List 10-15 things your product can do
2. List what's different about how you do them
3. Pick customers who got exceptional value
4. What was different about their situation?
5. What was different about how they used it?
6. What do they tell others about you?
7. What would they be doing without you?
8. What could they do now that they couldn't before?
9. List 3-4 use cases ordered by value
10. Pick ONE position that resonates most
```

## Week 3-4: Validation

### Customer Interviews (5-10)

**Call existing customers + prospects to test your positioning**

**Script**:
```
"I'm working on how we position [Product]. I'd love your feedback on this 
positioning statement: [Read your statement]. Does this resonate? What would 
you change? What's missing?"
```

**Track**:
- Do they get it in <30 seconds?
- What resonates most?
- What confuses them?
- What would they add?

### Competitive Analysis

**Deepening**: Talk to customers about competitors/alternatives they considered

**Ask**:
```
"When you were evaluating solutions, what other options did you look at? 
Why did you choose [us]? What were you worried about?"
```

## Week 5-6: Operationalization

### Create 23 Strategic Artifacts

```
Positioning Layer (5):
├─ Positioning statement (1-2 sentences)
├─ Differentiation statement
├─ Value proposition (overall)
├─ Brand promise
└─ Brand guidelines

Persona Layer (6):
├─ Persona 1 (detailed profile)
├─ Persona 2
├─ Persona 3
├─ Their goals
├─ Their pain points
└─ Proof that matters to each

Messaging Layer (7):
├─ Primary message (Tier 1)
├─ Secondary messages (Tier 2)
├─ Segment-specific messaging x3
├─ Proof point hierarchy
└─ Messaging do's and don'ts

Strategy Layer (5):
├─ Competitive positioning
├─ Unique selling proposition
├─ Category definition
├─ Market positioning
└─ Sales strategy
```

### Brand Guidelines Document

```
Voice & Tone:
- Formality level
- Emotional tone
- Word choices to avoid
- Example sentences

Visual Identity:
- Logo usage
- Color palette
- Typography
- Imagery style

Messaging:
- Core message
- Supporting messages
- What NOT to say
```

### Sales Playbook

```
For Each Buyer:
├─ Opening (what to lead with)
├─ Problem exploration (questions to ask)
├─ Solution narrative (how to position)
├─ Objection handling (common objections)
└─ Closing (what to ask for)
```

### Content Calendar

```
Month 1:
├─ Week 1: Thought leadership (problem definition)
├─ Week 2: Solution narrative
├─ Week 3: Proof point (case study)
└─ Week 4: Call to action (lead magnet)

Month 2-3: Rinse and repeat with different angles
```

## Key Points

- **Same process for all products**: Ask-AI, Risk Scoring, eCourt use identical exercises
- **Different frameworks applied**: Ask-AI uses Moore, Risk Scoring uses JTBD, eCourt uses Lean Canvas
- **Customization by buyer**: Same positioning, different emphasis for CTO vs. CFO vs. User
- **Output is actionable**: These 23 artifacts feed directly into content, lead gen, and sales
