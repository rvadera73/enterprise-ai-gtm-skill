## Option B: Adapt the Example for Your Product (1 hour)

If you have a different product (Risk Scoring, MLOps, etc.):

### Step 1: Copy the Example (5 min)
```bash
mkdir products/Your-Product-GTM
cp -r examples/Enterprise-AI-Foundry/* products/Your-Product-GTM/
cd products/Your-Product-GTM/
```

### Step 2: Customize Each Asset (50 min)

**A. Whitepaper** (15 min)
- Open `whitepaper.html` in text editor
- Find `<h1>` tags (replace product name)
- Find case study examples (replace with your use cases)
- Find "Ask-AI" references (replace with your product)
- Find "fragmentation" problem (replace with your specific problem)
- Save

**B. One-Pager** (10 min)
- Open `onepager.html` in text editor
- Update title
- Update left column (your specific problem)
- Update middle column (your 5-stage framework)
- Update right column (your impact metrics)
- Save

**C. LinkedIn Posts** (20 min)
- Open `linkedin-campaign.md`
- Replace problem statement (Day 1)
- Replace case examples (Day 3)
- Replace framework name (Day 8)
- Replace use cases and details throughout
- Keep structure and narrative arc

**D. Guides** (5 min)
- Update CTAs in `quick-start-checklist.md`
- Update product references in `marketing-guide.md`

### Step 3: Validate (10 min)
- Open updated `whitepaper.html` in browser (does it look right?)
- Open updated `onepager.html` in browser (correct content?)
- Read a few posts from `linkedin-campaign.md` (sound authentic?)

**That's it.** You now have a complete, customized marketing system.

## The Three Stages of This Skill

### Stage 1: Strategic (What You Provide)
```
Input:
- Product name (e.g., "Enterprise Ask-AI Service")
- Target problem (e.g., "Enterprises rebuild AI systems repeatedly")
- Solution brief (e.g., "Reusable AI infrastructure platform")
- Target persona (e.g., "Federal CIO")
- Key differentiators (e.g., ["Built for compliance", "Multi-tenant"])
- Business strategy (optional, can use defaults)

Output:
- Strategic positioning document
- Market analysis (TAM/SAM/SOM)
- Competitive positioning
- Go-to-market motion
```

### Stage 2: Content Creation (What We Generate)
```
Input:
- Strategic analysis from Stage 1
- Industry/audience specifics
- Key insights and evidence

Output:
- Whitepaper.html (4 pages, thought leadership)
- OnePager.html (1 page, visual summary)
- LinkedIn Campaign (14 posts, complete)
- Operational guides (execution playbook)
```

### Stage 3: Execution (What You Do)
```
Input:
- All generated assets from Stage 2
- 45 minutes per day for 2 weeks
- Willingness to engage in comments

Output:
- 400+ followers
- 5-10 inbound conversations
- 2-3 demo calls booked
- First customer by day 90
```

## The Daily Routine (Once You Start)

### Before You Begin
- Set reminder for Monday 8 AM
- Have LinkedIn open
- Have post copy available

### Each Day (45 minutes)
1. **Post** (15 min): Copy post from campaign, paste to LinkedIn
2. **Engage** (30 min): Respond to comments on today's post + previous posts

### Weekly (Friday)
- Compile insights from that week's comments
- Identify hot leads
- Note what resonated + what didn't
- Plan next week's engagement strategy

## Common Questions

**Q: Do I need to memorize all the materials?**
A: No. Just follow the daily checklist. Materials are reference docs.

**Q: Can I modify the posts?**
A: First week: Use exactly as written. Week 2+: Adjust based on feedback.

**Q: What if I don't have time for 45 min/day?**
A: Minimum viable: 20 min/day (post + respond to 3-5 comments). Less ideal but works.

**Q: Should I hire someone to do this?**
A: Not recommended. Personal authenticity is the asset. Posts from the founder/CEO work best.

**Q: Can I do this for multiple products simultaneously?**
A: Yes, but not both weeks 1-2. Launch one, succeed, then launch the next.
