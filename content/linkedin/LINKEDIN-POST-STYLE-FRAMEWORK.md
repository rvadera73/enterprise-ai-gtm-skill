# LinkedIn Post Style Framework (video-paired GTM posts)

Derived 2026-08-13 by diffing an AI-drafted post against the author's actual published
edit (RiskModelForgeIQ Post 4, `urn:li:activity:7493589542583701504`). Five structural
upgrades the draft was missing — apply these by default to any future GTM LinkedIn
post, for any product, not just RiskModelForgeIQ.

## 1. BLUF first, no callback recap before the point
Open with the single headline claim (the video's own storyboard BLUF/hook, if one
exists) in the first line or two. Don't open with "last post covered X, this post
covers Y" — that's a permitted second beat, never the opener. See
[[gtm-linkedin-post-bluf-not-video-recap]] for the earlier finding this builds on.

## 2. Numbered list for 2+ parallel mechanisms, not bold-prefixed prose
When a post describes two or more structurally parallel things (mechanisms, pillars,
capabilities), use an actual numbered list with a short bold label per item
("1. Gate One Rule Stack: ...", "2. Live Model Arbitration: ..."), not paragraphs each
starting with a bolded phrase. The numbered form reads faster and scans better on
mobile than inline-bold prose.

## 3. One standalone pull-quote line
Include exactly one short, punchy sentence (or two-sentence pair) that stands alone as
the post's most quotable line — the thing someone would screenshot. Draft it
separately from the explanatory prose; don't rely on the explanatory sentences to
double as the quotable one. Example: "You're not just monitoring models. You're
governing what happens when the models are uncertain."

## 4. Rule-of-three triplets over full sentences for qualities
When describing what changed about a capability, prefer a three-word/phrase triplet
("adjustable, measurable, and reversible") over a full explanatory sentence saying the
same thing. Triplets read punchier and are more memorable in a scroll feed.

## 5. Echo the paired video's own strongest line back into the post
If the video's storyboard/script has a distinct closing metaphor or line (e.g. "a
shift from black box to glass house"), reuse it verbatim in the post rather than
paraphrasing or dropping it. This is what visibly ties the post and video together as
one artifact instead of two independently-written pieces — a returning reader
recognizes it.

## 6. Hashtag named entities, not just body copy
When the positioning already names specific customers/agencies/verticals explicitly
in body copy (see [[riskmodelforgeiq-gtm-decisionops]]'s "agencies now named
explicitly" rule), also add them as hashtags (`#CBP #CMS`) — extends the same
explicit-naming rule to hashtag selection, don't stop at the body text.

## How to apply
Treat this as a pre-publish checklist for any AI-drafted LinkedIn post pairing with a
demo video, alongside the existing playbook (`content/video/GTM-ASSET-PLAYBOOK.md`)
and [[gtm-content-no-comment-callbacks]]. Draft against all six; if the author's own
edit still improves on the draft afterward, add the new pattern here rather than
letting the lesson live only in that session's memory.
